## Ghost Auto Clicker v1.2.2

### Fixed: icon in File Explorer
- The ghost icon now shows in every File Explorer view (small, medium, large and extra large icons, list and details).
  Before, some views showed the default icon.

If Explorer still shows the old icon for a file you downloaded before, Windows is showing a cached copy:
rename the file or move it to another folder and the ghost appears.

No other changes since v1.2.1.
