
## Downloads

- **GhostAutoClicker.exe**: the Windows app, nothing to install. Download it and run it.
  Windows may show a SmartScreen warning because the exe isn't signed: click **More info → Run anyway**
  (or right-click the file → Properties → tick **Unblock**).
- **autoclicker.py**: the same app as a script. Run it with `python autoclicker.py` (Python 3.8+, no extra packages).
