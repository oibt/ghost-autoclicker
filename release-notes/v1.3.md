## Ghost Auto Clicker v1.3

### New: clicking games like Roblox
Many games ignore normal background clicks. The **Windows** tab now has two game modes:

- **Background for games**: clicks in the background like before, but first tells the game window it's the
  active one. Try this first: your mouse stays free.
- **Quick switch (games like Roblox)**: for games that only accept real input while they're in front.
  On every click it brings the game forward for a split second, clicks, then puts your window and your mouse back.
  - Use a low speed (1–5 clicks a second).
  - The game can be behind other windows, but not minimized.
  - If clicks are missed, raise **Quick switch wait** (Windows tab → Advanced).

When you add a point on a Roblox window, the app suggests Quick switch.

Heads up: using an auto clicker may be against a game's rules, so check them first.
