## Ghost Auto Clicker v1.3

### New: clicking games like Roblox
Many games ignore normal background clicks. The **Windows** tab now has two game modes:

- **Background for games**: clicks in the background like before, but first tells the game window it's the
  active one. Your mouse stays free.
- **Quick switch (games like Roblox)**: for games that only accept real input while they're in front
  (tested with Roblox). It brings the game forward for a split second, clicks, then puts your window and your
  mouse back. The game can be behind other windows, but not minimized.

### Quick switch tab
Settings to keep Quick switch out of your way while you use other apps:

- **Only click when I'm not using the computer** (on by default): waits until you haven't touched the mouse or
  keyboard for a moment (0.5 s by default), so it never grabs focus while you're typing or moving the mouse.
- **Clicks per switch**: several clicks each time the game comes forward, so it switches less often.
  The average speed stays the same.
- **Faster switching**: clicks as soon as the game is actually in front instead of always waiting
  (**Max wait for the game**, 100 ms by default).
- **Make the game see-through while clicking** (experimental, off by default): hides the flash when the game
  comes forward. The game comes back when you press Stop or close the app.

When you add a point on a Roblox window, the app suggests Quick switch.

Heads up: using an auto clicker may be against a game's rules, so check them first.
